# CodeStable

## 上游项目（Fork 来源）

**本项目 Fork 自：[codestable/CodeStable](https://github.com/codestable/CodeStable)。**

CodeStable 是一组可复用的、独一无二且无可替代的 AI 编程技能

## 安装

```sh
npx skills@latest add Sisyphean-a/CodeStable --all -g
```

## 技能

`cs`、`cs-audit`、`cs-brainstorm`、`cs-code-review`、`cs-docs`、`cs-docs-neat`、`cs-domain`、`cs-epic`、`cs-feat`、`cs-feedback`、`cs-goal`、`cs-issue`、`cs-keep`、`cs-note`、`cs-onboard`、`cs-refactor`、`cs-req`
