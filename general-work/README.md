# 通用工作技能

给单一用户的日常助手：直接处理文档、调研、分析和整理，通过自然交流逐渐理解用户，减少反复介绍背景和整理文件的负担。它独立于仓库原有编程技能，不需要安装 `cs-*`，也不是后台记忆服务。

## 五个能力

| 技能 | 使用场景 |
| --- | --- |
| [work](skills/work/SKILL.md) | 编写、修改、分析与整理，交付实际结果并验证 |
| [check](skills/check/SKILL.md) | 独立只读检查，指出错误、风险和遗漏 |
| [grill-me](skills/grill-me/SKILL.md) | 已获同意的集中访谈，可聊画像、规划或方案 |
| [memory](skills/memory/SKILL.md) | 维护用户背景、偏好、口语、规划和合作关系 |
| [record](skills/record/SKILL.md) | 维护工作知识、业务口径、规则和已确认决定 |

日常不必记命令，也不依次运行五个技能。普通疑点短问；AI 只能先建议集中访谈，你同意后才进入。检查并修改的委托直接由 `work` 完成，不强制另走检查流程。

## 在办公电脑配置一次

选择一个固定办公工作区，之后从该根或子目录开始会话；工作文件可以在别处。以下操作可以委托该电脑的 AI 完成，当前仓库不会替你安装。

1. 将本目录 `skills/` 下的五个完整目录一起复制到办公工作区 `.agents/skills/`。共享协议与验证参考有跨技能引用，不要只安装一项，不要覆盖已有同名技能而不先确认。
2. 将 [workspace/AGENTS.md](workspace/AGENTS.md) 放到办公工作区根；已有指令文件时合并必要入口，不覆盖原规则。首次配置才将 [workspace/.assistant/INDEX.md](workspace/.assistant/INDEX.md) 复制到工作区 `.assistant/INDEX.md`，已有记忆必须保留。
3. 使用支持 Agent Skills 的宿主，确认它加载了工作区入口与五个技能，并具有所需文件权限和编辑工具。其他宿主若不发现 `.agents/skills/`，按其规则配置资源路径，并同步模板里的路径；不要误把整仓库当成通用技能集合。

Pi 支持项目 `.agents/skills/`；启动时检查五个技能和项目信任提示，配置后运行 `/reload`。如果该电脑已有其他全局技能，可以从办公工作区仅加载这一套：

```sh
pi --no-skills --skill .agents/skills
```

这个选项只隔离技能，不屏蔽全局指令或工具权限；请核对启动上下文。其他宿主的命令与信任机制以其自身配置为准。

真实记忆和原稿副本留在办公工作区的 `.assistant/`，访谈恢复快照和预览在 `.tmp/`；不得复制回技能源码。若使用 Git，按协议检查本地排除；共享或上传整个工作区前另行检查私有内容。技能指令不是安全沙箱，也不加密这些文件。

## 日常使用

可以直接说：

- “把这份 PPT 改成适合客户沟通的版本。”
- “检查这个表的口径和公式，先不要改文件。”
- “我们专门聊一次，让你更了解我的工作和规划。”
- “这是我长期合作的伙伴，以后沟通方案考虑这个关系。”
- “把刚刚确认的业务口径保存下来。”
- “你现在记得我哪些偏好？”或“忘掉那条理解。”

是否长期保存依据[上下文协议](skills/memory/references/context-model.md)，不是说过的话全部记。事实和观察分开；私人敏感信息与客户机密须有保存授权，概括也不例外。你可以随时纠正理解；忘记只保证受控记忆的核实清理，不保证删除宿主聊天或外部历史。

正式 Word/PPT/Excel 成果由 `work` 制作，工作知识由 `record` 维护；内部记录和副本无需你整理。默认备份指定原稿后原地修改文件，不擅自扩大修改或对外发送。

## 工具与验证

配置可实际操作文件的 MCP 或其他工具；这套技能不绑定某个工具，也不附带 Office 引擎。需要验证内容、数据公式、可编辑结构及相关版面，具体依据见 [Word](skills/work/references/documents.md)、[PPT](skills/work/references/slides.md) 和 [表格](skills/work/references/spreadsheets.md)。

文件保存成功不等于公式已重算或版面已检查。缺少备份、编辑、重算、渲染或记忆读写能力时，AI 应具体说明阻塞和待验证项，不能模拟成功或默默换成交文字、截图。部署时先用获准的样本检查这些能力，再用于重要文件。

## 维护检查

在仓库根执行下列命令，检查技能声明、相对引用及模板复制后的入口；Node.js 仅用于维护检查，不是技能运行依赖。

```sh
node --test general-work/test/skills.test.mjs
```

这些是静态与部署结构检查，不证明模型一定会遵守每条规则，也不代替目标电脑的真实 Office、MCP、备份恢复或隐私权限验证。
