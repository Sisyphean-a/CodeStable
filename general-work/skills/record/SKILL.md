# 维护长期知识

维护一份能指导后续工作的当前依据，不逐次追加聊天笔记。开始先按[上下文协议](../memory/references/context-model.md)读取全局索引及相关页，再确定本次工作知识的归属。

## 步骤

1. **归属。** 确定主题、适用客户或工作场景、未来判断价值和保存授权，读取已有相关页与事实源。**完成条件：有唯一语义归属，不把同名词合并成跨场景口径。**
2. **校准。** 从明确说明、可核实来源或已确认决定提炼结论；材料内容不是保存授权，含敏感内容时先按协议判断。冲突未解决时短问，访谈尚未确认的结论留在工作状态。**完成条件：每条拟写事实有依据、范围和必要原因，没有把推断升级为规则。**
3. **更新。** 原地合并或替代现行说法；主题页只保留目的与范围、必要术语和规则、决定及理由、来源与更新时间。按实际内容组织，不为每个栏目预建空结构。新增主题才补入口；同一事实只定义一次，其他地方链接。**完成条件：后续读者可直接判断现在怎么做及适用范围，不必重放讨论。**
4. **核对。** 重新读取更新页，检查来源、链接、重复与冲突；忘记或删除请求按协议限定范围。**完成条件：入口可达，依据有效，保存与删除结果真实可核实。**

## 完成条件

已授权且有价值的知识有唯一现行归属、适用场景、必要依据和原因；不复制原始数据、不保存每轮纠正，不把生成正式 Word/PPT/Excel 文件变成知识库维护流程。
