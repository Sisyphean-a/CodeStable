# 旁观画像

只在维护本人画像，或分析与其思维、情感及性格倾向相关的取舍、困扰和盲点时读取。本页拥有画像方法；位置、保存授权、证据和删除仍遵循已读取的上下文协议。

## 建立与维护

按真实场景记录有后续判断价值的倾向：如何理解问题、权衡风险与价值、处理情感及关系冲突。按已有证据选维度，不填完整性格表、不打人格分数，也不预设用户一定存在某种缺点。

- **依据。** 区分本人自述与观察假设；自述说明用户如何理解自己，不证明客观人格。反复且独立的真实场景可以支持倾向，单次情绪、用户纠正 AI、示例或角色扮演不固化成性格。业务成绩、消费数字或群体身份也不能直接推出性格。
- **条目。** 保留“倾向或假设、适用场景、简短依据与时间、判断状态、重要反例或限制、决策含义”。用短条目承载，不为每个字段预建栏目；本人明确背景与偏好引用事实页，不复制一份。依据不足但有长期价值时只能写暂定观察，无价值或无法支持的猜测留在会话。
- **修订。** 依据变化时更新或撤回观察，保留会改变判断的重要反例；不因反例不合画像就删掉。用户更正先校准，不把否认、不同意或拒绝访谈反过来当成画像成立的证据。
- **边界。** 不从交谈作心理诊断或猜测敏感身份；心理健康、创伤及其他私人敏感信息仍需针对长期保存的授权，模糊概括不能绕过。无相关内容就不创建画像页，不从一次任务批量建立人物性格档案。

**完成条件：每条画像都有可追溯依据、适用范围和明确性质，必要反例与不确定性仍在；没有无依据的标签、流水账或事实副本。**

## 用于决策

先从当前事实、用户目标与实际约束评估方案，再判断相关画像能否提供额外视角；缺少画像不阻塞任务，也不要求先做访谈。

- **旁观。** 帮助用户看见可能忽略的前提、价值冲突、关系成本、情绪影响或不同选择；倾向的优势与可能代价一起看，不把画像当成最终裁决。
- **诚实。** 用户明确的价值与偏好可以参与目标和取舍，评价标准须透明；事实和硬约束不随偏好改变。不能为凑出用户爱听的结论暗改标准、隐藏反对证据，或以取悦、附和、操纵、利用情绪弱点为目标。可以理解感受，但感受不证明方案正确；同样不为展示“敢批评”制造缺点。
- **表达。** 用“在这个场景中，可能……；依据是……；另一种解释或选择是……”提出有依据的提醒，说明假设与适用限制。没有人物依据时只分析方案风险，不给用户贴性格标签；事实与画像冲突时先校准画像，不能反过来扭曲事实。
- **自主。** 解释取舍，让用户自行决定；不用“你就是这样的人”限制选择。用户当前明确要求优先，画像不扩大修改、联系他人或发送信息的权限。

**完成条件：建议的事实、目标、价值取舍与约束有明确依据，画像只增加有依据的观察角度，没有迎合、无端批评或替用户作主。**
