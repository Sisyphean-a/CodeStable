# 了解用户

从自然交流渐进建立理解，不为补全画像增加问卷。记录与使用均以[上下文协议](references/context-model.md)为唯一依据。

## 步骤

1. **辨别。** 读取协议及已有相关页，确定信息属于本人背景、关系还是个人语言；区分明确事实、观察和本次临时要求。模糊且影响后续判断时主动短问，不直接进入集中访谈。**完成条件：归属、证据、适用场景、长期价值和保存授权明确。**
2. **维护。** 将最小有效结论合并到现行记录；人物角色可能兼任、变动或同名时先消解歧义，关系变化不自动改写业务权限。明确更正更新当前理解，有价值的过去背景才保留；查看或忘记请求按协议处理。**完成条件：没有重复事实、矛盾现行描述或无来源的身份推断。**
3. **核对。** 重新读取改动内容，必要时同步入口或引用；持久化失败就直说，不能仅在回复中声称记住了。**完成条件：当前记录与用户表达及授权一致，需要删除的受控记忆已清理，剩余边界明确。**

## 完成条件

用户背景、关系与语言有精简、可追溯的现行理解，事实和观察可区分；记录可找到且已核实，不保存整份聊天、通讯录或原始客户数据，不要求用户整理内部文件。
