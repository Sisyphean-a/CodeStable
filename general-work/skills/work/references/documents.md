# 文档

适用于 Word、正文报告及 PDF 内容和版面；检查时只用下列验证依据，不修改原稿。

## 内容与结构

- 以读者、用途和所需结果组织正文，沿用原稿术语与结构，除非请求就是重组。
- 核对事实、引用、关键数字及表格口径；事实、推断、建议分开，不为完整感编造材料。
- 修改只覆盖请求范围，保留相关标题层级、样式、目录、编号、交叉引用、批注及修订语义。

## 格式与版面

编辑前核实真实格式及工具保全能力；`.doc`、带宏文件、受保护文档或 PDF 不因扩展名相近就按普通 `.docx` 处理。若需要转换且影响可编辑性、修订或布局，先确认。

版面相关修改检查分页、孤立标题、表格跨页、页眉页脚、页码、字体替换和文本溢出。需要更新目录或字段时执行真实更新，再核实结果；没有更新能力就指出具体待验证项。

PDF 预览可以帮助检查排版，但不能代替用户要求的可编辑 Word。无法保留可编辑结构时，不把整页截图或重新导出的 PDF 当作等价交付。

## 验证完成条件

重新读取真实文件，目标内容、引用与结构正确；涉及版面或字段的检查已有相应证据。缺少渲染、字段更新或格式支持时分别说明，不能只因文本提取成功就宣称排版通过。
