# 配置办公工作区

本技能独占整套技能的部署与初始化。其他技能只使用已配置好的工作区，不安装、不重复初始化；日常任务不触发本流程。

## 步骤

1. **目标与来源。** 确定办公工作区根；未给出且无法从当前目录判断时短问一次。核对来源：本技能所在目录的父目录须同时包含 `setup`、`work`、`check`、`grill-me`、`memory`、`record` 六个目录，缺任一项就停止，说明需要先在该电脑取得完整技能包。**完成条件：目标与完整来源都明确，没有猜测。**
2. **检查现状。** 只读核对目标 `.agents/skills/`、`AGENTS.md` 和 `.assistant/`。已配置、缺失、冲突分别记录；已有记忆或入口与本套冲突时先说明并短问，不覆盖。**完成条件：知道本次要新增什么，且没有待覆盖的用户内容。**
3. **部署。** 将六个技能目录整体复制到目标 `.agents/skills/`，保持同级关系，共享协议随 `memory` 一起到位；技能文件可整体刷新，`AGENTS.md` 只在缺失时创建、已存在时只补必要入口，`.assistant/INDEX.md` 只在首次创建。**完成条件：技能与唯一入口齐备，用户已有文件未被改写，重复运行不产生第二套记忆。**
4. **排除检查。** 按[上下文协议](../memory/references/context-model.md)核实目标 `.assistant/` 与 `.tmp/` 的排除状态，未排除或无法保证时按协议处理并在必要时暂停私有写入。**完成条件：私有记录与副本不会被提交，或阻塞原因明确。**
5. **验证。** 确认宿主加载了六个技能与工作区入口，并用一次只读请求核对入口可达及文件读写、编辑工具可用；Office 重算、渲染等能力按样本单独验证，缺什么报什么。**完成条件：可达性与必需能力已核实，缺失项如实列出。**

## 完成条件

办公工作区包含完整技能、唯一入口和可用记忆根；重复调用不覆盖用户文件、不重复初始化；部署说明只存在于本技能，日常技能与工作区入口都不复述初始化流程。
