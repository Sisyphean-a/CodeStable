# 项目记忆模型

这是 CodeStable 项目记忆的唯一读写协议；信息架构、加载和写入路由保持在同一文件，不再拆分补充协议。

## 权威顺序

冲突依次采用：当前代码和用户明确决定；`architecture/`、`requirements/` 当前态；`history/` 原因与证据；旧任务、审查和探索材料。代码、配置、目录、脚本和 `--help` 可直接表达的事实留在环境中；项目记忆只保存环境无法表达或取得代价高、且会影响未来判断的稳定信息。旧材料不能覆盖当前态。

## 工作状态

未闭合讨论、探索证据和依赖留在 Pi 会话或调用技能的规划面。确需跨会话恢复时，写入仓库根 `.tmp/<mechanism>/` 的可丢弃快照；首次写入前须用 `git check-ignore` 确认 `.tmp/` 已被忽略，否则加入 `.git/info/exclude`，无法保证时让用户处理。变化整体确认后一次晋升，完成即删除快照。

## 按范围加载

由改动路径确定 `workspace`、`package:<name>` 及直接映射的 `context:<name>` 或 `shared:<name>`，只读：

1. `.codestable/attention.md`；
2. `.codestable/architecture/INDEX.md`；
3. 目标包页面及其直接链接的共享页；
4. `requirements/CONTEXT.md` 的作用域地图与工作区条目；
5. 与目标直接相关的 `requirements/contexts/` 或 `requirements/shared/` 页面。

历史、读者文档和旧证据不在默认工作集。单仓多包只保留一个根 `.codestable`。

## 当前态位置

- `architecture/INDEX.md`：范围地图、包归属和入口。
- `architecture/packages/<package>.md`：包职责、边界、依赖、差异和代码锚点。
- `architecture/shared/<topic>.md`：一个跨包契约或共享机制。
- `requirements/CONTEXT.md`：领域地图及没有更窄所有者的工作区语言与规则。
- `requirements/contexts/<context>.md`：一个领域边界拥有的语言与规则。
- `requirements/shared/<scope>.md`：若干领域共同拥有且没有单一所有者的语言与规则。

一个事实只定义一次，其他范围只链接并说明本范围影响。新增或移动页面时同步最直接的索引或作用域入口；当前规则须能由范围、规范词或代码锚点命中。

## 领域上下文

领域事实按语义所有权归档，不按讨论位置或代码复用归档。包是实现边界，不自动成为领域边界；跨包引用不会扩大术语作用域。同名不同义时分别定义并使用限定名；范围未确认时保留歧义，范围错误时移动定义并从原处链接。版式见[领域上下文格式](domain-context-format.md)。

## 检索契约

先读目标范围当前态。只有询问原因、证据冲突或规则演进时，才用范围、规范词及必要旧称、当前页面、代码路径或符号检索少量历史；证据足够即停止。读者文档沿用现有 README、包索引或发布位置，不进入默认工作集，也不为单篇文档新建总索引。

## 记忆门槛

先把同一任务的局部结论合并成能独立说明“改变了什么”的变化单元，再问：未来 AI 不知道它或其原因，是否会误判？

- 不会：不写 `.codestable`；格式化、机械重命名、生成文件和普通样式通常止于 Git。
- 会但当前规则未变：只追加历史。
- 接口、模块边界、业务规则或既有假设变化：更新唯一当前态并追加历史。
- 安全、数据、不可逆操作、跨包协议或高代价取舍：把必要原因写入受影响的唯一当前态，并追加历史。

写入前以代码和明确决定校准，用现在时更新并删除被替代说法。结论须有准确范围、规范词、代表性代码锚点和必要原因；重试只补缺失内容，并检查矛盾当前态、复制事实和重复历史。

## 历史

初始化时必须创建 `.codestable/history/`；条目写入 `history/YYYY-MM.md`，不建任务目录。标签仅用 `功能`、`缺陷`、`重构`、`演进`：新增外部能力、恢复契约、保持外部契约的内部调整、主动改变规则或架构分别对应四类。月文件按日期逆序，同日保持写入顺序；旧格式保持原样。

```md
- 日期 · [功能|缺陷|重构|演进] 一句话结果。范围：workspace|package:<name>|context:<name>|shared:<name>
  原因：为什么改变。
  当前依据：更新过的架构或领域上下文；没有则写“无”。
  证据：提交、代码路径或原始历史链接。
```

历史只索引能减少未来误判或昂贵考证的结果、原因、当前依据和证据；规则正文由当前态唯一维护，常规过程交给 Git、CI 与代码。
