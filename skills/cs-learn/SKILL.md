# 代码学习

以当前项目为教材，在本次对话内让用户形成可验证的理解；只需通过图、树或 HTML 看懂现成关系时使用 `show-me`。

1. **定点。** 把学习目标落到真实代码入口、符号、调用关系和具体技术来源；同名概念先核对 import、依赖和用法，不凭名称猜测。只询问会改变讲解深度的已有知识或目标。**完成条件：本轮只有一个可定位的学习目标，项目事实和必要先验均已明确。**
2. **带读。** 先说明目标代码在项目流程中的位置，再按语义块讲实现，最后只补理解这些代码必需的通用知识。学习单个函数时追踪调用者、参数来源、内部块、分支和结果；学习全线路时先给有序代码锚点，再逐段深入；学习陌生技术时从项目用途进入，并与用户熟悉的写法对照。每个片段附仓库相对路径和符号；当前代码与测试是项目行为依据，官方一手资料只用于核实通用语义。**完成条件：每轮只推进一个能独立掌握的片段，用户知道正在学什么以及它为何存在。**
3. **验证。** 在关键处让用户预测分支、复述职责或解释一个小型假设改动，再回到代码或聚焦检查核实；用户要求直接讲时不强制测验。结束时只总结已经掌握、仍然模糊和可选的下一个代码锚点。**完成条件：用户能说明目标的输入、关键实现和结果，并正确判断至少一个分支或变化。**

始终分开表达项目当前行为、已确认意图、技术通用规则和推测；已确认意图必须附项目资料依据，代码效果本身归入当前行为或推测。相邻知识只列为可选方向，不自动扩展课程；不写业务代码、学习记录、项目记忆或读者文档。

## 完成条件

学习目标已由当前代码支撑并经过一次理解验证；未决点可定位，本次对话结束后没有需要维护或清理的学习文件。
