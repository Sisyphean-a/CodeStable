# 跨会话检查点

在仓库根 `.tmp/checkpoints/<task-name>.md` 维护每个大型任务的**当前快照**；它只用于续接，不是计划、过程历史或项目记忆。

## 选择

任务名只作为单个安全文件名，不接受绝对路径、路径分隔符或 `..`。未给任务名时：恰有一个检查点则自动选择；没有检查点时，`save` 从当前目标生成短名称，其他操作说明不存在；有多个时列出名称并让用户选择。

## `save`

首次写入前，读取[项目记忆模型](../cs-domain/references/memory-model.md)的“工作状态”并落实 `.tmp/` 忽略规则。若目标已存在，先读旧快照，保留仍有效的用户重点；再从本轮对话、当前代码和 Git 状态校准并原地覆盖，只写下一会话无法廉价恢复的内容：

- 目标与完成判断；
- 用户明确的重点、约束和取舍；
- 已完成、正在进行、下一步；
- 阻塞与未决；
- 代码、文档、Issue 或提交锚点；
- 更新时间，以及分支、HEAD、相关未提交路径和最近验证结果。

已有资料只链接，不复制正文；省略敏感值、完整对话、代码、diff、工具过程和流水账。**完成条件：快照短小、当前、可定位，下一会话无需重放旧对话即可继续。**

## `resume`

读取选定快照并核对当前分支、HEAD、相关路径和验证状态；漂移项显式标记，不静默改写快照。返回目标、用户重点、当前进度、下一步、阻塞和漂移，作为本会话后续请求的上下文。**完成条件：用户能直接给出下一动作，无需复述任务背景。**

## `done`

只有用户明确表示该任务完成时，删除选定检查点；目录为空时一并删除。检查点不晋升为项目记忆，任务产生的稳定结论仍由其主责技能按记忆门槛处理。**完成条件：仅目标检查点已删除，其他任务不受影响。**
