# 剪枝

结果必须是更短、更准确的默认工作集。首次初始化或整体迁移属于 `cs-onboard`。

开始定域前，只读[项目记忆模型](../cs-domain/references/memory-model.md)的“按范围加载”小节，并按该顺序取得当前工作集。

## 步骤

1. **定域。** 从改动路径或用户目标确定 `workspace` 或 `package:<name>`，只读该范围的注意力规则、当前态、直接共享依赖和活动旧单元。**完成条件：无关包被排除。**
2. **裁决。** 每份候选只能选一项：保留当前事实、提炼进权威位置、用新依据替代旧结论、删除已吸收过程材料。**完成条件：每份候选都有唯一裁决。**
3. **执行。** 删除源材料前先写入有效结论，保留代码锚点、日期和 Git 或原始证据；ADR 只能标记替代。**完成条件：没有唯一证据丢失。**
4. **校准。** 将保留结论与代码和已确认决定对照；旧文档只描述历史行为时恢复当前真相，只有权威证据真正冲突才询问。**完成条件：当前态不与代码冲突。**
5. **删除。** 清除已完成计划、常规验证、文件清单、重复报告、已吸收探索和空过程目录。**完成条件：范围内默认文件集变短，或确认没有沉积可删。**
6. **验证。** 检查链接、共享事实复制、替代指针和范围泄漏。**完成条件：每条保留事实可从当前索引到达并追到证据。**

只有裁决要求写当前态或历史时，才读项目记忆模型的“当前态位置”和“记忆门槛”小节。

## 完成条件

范围内所有候选已处理，当前态与代码一致，可复用证据可追溯，且没有新增清理报告。
