# 功能

直接交付可观察结果，不创建并行规划流程。

## 边界

本技能处理有意行为变化。期望行为不变则是重构；现有行为违反既定契约则是缺陷。证据改变分类时，编辑前重新归类。

开始定域前，只读[项目记忆模型](../cs-domain/references/memory-model.md)的“按范围加载”小节，并按该顺序取得相关当前态。

## 步骤

1. **定域。** 从可能改动路径确定 `workspace` 或 `package:<name>`，读取相关当前态和代码。**完成条件：现有契约、期望结果和受影响边界明确。**
2. **实现。** 用最小完整改动交付结果，设计沿用仓库现有约定，除非功能本身改变约定。**完成条件：真实路径中的所有请求行为及相关错误/空状态都存在。**
3. **验证。** 运行能证明可观察结果和受影响契约的聚焦检查；跨边界时扩大到集成或回归。**完成条件：新证据覆盖全部必需路径，没有已知漏测。**
4. **记忆裁决。** 先判断未来是否会因不知道原因而误判；越过门槛时才读项目记忆模型的“记忆门槛”和对应写入小节。**完成条件：明确无需文档，或已完成历史、当前态或架构决定记录。**

只有触及安全、持久化数据、生产操作、不可逆外部影响或核心跨包协议时，才在风险动作前读[高风险分支](../cs-code-review/references/high-risk.md)。

## 完成条件

可观察结果有效，必要验证通过，高风险义务已结清，项目当前态不与实现冲突；不创建功能计划、检查清单、质量报告、验收或常规审查产物。
